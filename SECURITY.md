# Security Policy

## Supported Versions

Ayur Clinic is currently under active development.

Security updates and improvements are applied to the latest version of the project.

## Reporting a Vulnerability

If you discover a security vulnerability or potential security issue, please do not open a public GitHub issue.

Instead, report the issue privately to the project maintainer with:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any relevant screenshots or supporting information

The report will be reviewed and appropriate action will be taken to investigate and resolve the issue.

## Security Principles

The project is being developed with a privacy-conscious and security-focused approach.

Key principles include:

- Collecting only the minimum personal information required
- Avoiding the collection of medical records, symptoms, or other special category health data through public website forms
- Using secure backend services for future data handling
- Applying appropriate database access controls
- Restricting public access to sensitive data
- Reviewing third-party dependencies and project configuration
- Keeping secrets and environment variables outside the public repository

## Planned Data Handling

Future callback or contact workflows are intended to collect only the minimum information necessary for communication, such as:

- Full name
- Email address
- Phone number

Personal data retention and access controls will be implemented as part of the backend architecture before these features are released.

## Scope

This security policy applies to the Ayur Clinic website repository and its associated application infrastructure.
