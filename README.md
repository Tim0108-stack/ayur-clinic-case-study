## Current Implementation

The project is currently under active development. The screenshots below show selected parts of the current implementation and reflect the design direction, component system, and user experience being developed.

Features, layouts, and implementation details may evolve before the initial release.

### Homepage

![Ayur Clinic homepage](./assets/screenshots/homepage-hero.png)

The homepage establishes the visual direction for the platform, combining a calm healthcare-focused interface with clear navigation, service discovery, and accessible calls to action.

### Pregnancy Calculator

![Pregnancy calculator](./assets/screenshots/pregnancy-calculator.png)

The pregnancy calculator is designed as an interactive patient resource, providing multiple calculation methods within a focused and easy-to-use interface.

### Pregnancy Resources

![Pregnancy resources](./assets/screenshots/pregnancy-resources.png)

The pregnancy resources section provides patients with structured guidance and access to educational material throughout different stages of pregnancy.

### Clinic Location

![Ayur Clinic location](./assets/screenshots/clinic-location.png)

The location section provides clear clinic information, map access, and nearby parking guidance to help patients plan their visit.
