# SEO

> Search engine optimisation strategy for the Ayur Clinic website.

## Overview

Search engine optimisation is considered during the development of the Ayur Clinic website rather than being added after the platform is complete.

The goal is to provide search engines with a clear understanding of the website, its pages, and its content while maintaining a useful and accessible experience for patients.

The SEO strategy focuses on:

- Clear site structure
- Meaningful page content
- Semantic HTML
- Structured metadata
- Page-specific titles and descriptions
- Search-friendly URLs
- Performance
- Mobile usability
- Accessible content

The objective is to build a strong technical and content foundation rather than relying on shortcuts or artificial optimisation.

---

## Site Structure

The website is organised into clear sections based on the information patients are likely to look for.

Core areas include:

- About
- Meet the Team
- Services
- Patient Resources
- Contact
- Privacy Policy
- Cookie Policy

This structure helps users navigate the website and provides a logical hierarchy for search engines.

Each page should have a clear purpose and should avoid combining unrelated topics unnecessarily.

---

## Metadata

Each important page should include relevant metadata.

This includes:

- Page title
- Meta description
- Canonical URL where appropriate
- Open Graph metadata
- Social sharing metadata where appropriate

Metadata should accurately describe the content of each page.

Titles and descriptions should not be duplicated across unrelated pages.

A central SEO configuration can provide default values while allowing individual pages to define their own metadata.

---

## Page Titles

Each page should have a clear and descriptive title.

Titles should communicate the primary purpose of the page.

Examples of page types include:

- Ayur Clinic | Private Obstetrics & Gynaecology Consultancy
- About Ayur Clinic
- Meet the Team
- Obstetrics & Gynaecology Services
- Patient Resources
- Contact Ayur Clinic

The final wording will be refined based on the approved site content and search strategy.

---

## Meta Descriptions

Meta descriptions should provide a concise summary of each page.

They should help users understand what they can expect before visiting the page.

Descriptions should be:

- Relevant to the page
- Clear and readable
- Unique where possible
- Written for users rather than keyword repetition

---

## Semantic HTML

Semantic HTML supports both accessibility and search engine understanding.

Pages should use meaningful elements such as:

- `header`
- `nav`
- `main`
- `section`
- `article`
- `footer`

Heading structure should clearly communicate the hierarchy of the content.

The main page topic should generally be represented by a single primary heading.

Supporting sections should use logical heading levels.

---

## Content Structure

Content should be organised around clear topics and patient needs.

Pages should prioritise useful information rather than creating content solely for search engines.

The content strategy should focus on:

- Clear explanations
- Relevant services
- Patient guidance
- Practical clinic information
- Well-structured resources

Content should avoid unnecessary keyword repetition or artificial optimisation.

---
